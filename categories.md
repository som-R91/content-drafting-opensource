# categories.md — Content Category Registry

This file is the single source of truth for all content categories used in this workspace. Every published piece must have exactly one category drawn from the Active Categories list below. Categories are used by the website filter UI — they must be consistent across all content and CMS JSON files.

**How categories are added:** Claude Code proposes a new category during a draft session, pauses for your explicit confirmation, and only then adds it here. Categories are never invented ad hoc inside a draft or added without a checkpoint pause. This ensures the category list stays coherent and useful as a filter.

**Format:** Each category is a noun phrase, specific enough to be a meaningful filter label, broad enough for multiple future articles to share it, and grammatically consistent with the other entries.
